# The Long Road to GTA VI

Неофициальный фанатский рекап 13 лет ожидания GTA VI (2013–2026): таймлайн из 45 событий, раздел мемов «We got X before GTA 6», живая инфографика и обратный отсчёт до релиза 19 ноября 2026. Семь языков: EN (по умолчанию), RU, ES, FR, TR, JA, ZH.

## Запуск

Сборка не нужна, это статический сайт:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Структура

- `index.html`: разметка (херо с таймером, инфографика, таймлайн, мемы, финал с кнопками «Поделиться»)
- `css/style.css`: стили и дизайн-токены (палитра в `:root`)
- `css/fonts.css`, `fonts/`: шрифт Onest (OFL), локально; японский и китайский шрифты подгружаются из Google Fonts только при выборе языка
- `js/data.js`: **метаданные** событий (дата, категория, источник, картинка), список мемов и параметры инфографики
- `js/locales/<код>.js`: **все тексты** на конкретном языке, ключи совпадают с `id` в `data.js`
- `js/main.js`: рендер, переключатель языка, фильтры, таймер, живые счётчики, «текучий» градиент
- `og.png`: превью для X / Threads (1200×630)

## Язык

Порядок выбора: `?lang=ru` в адресе → сохранённый выбор → английский. Для поста на конкретном языке давай ссылку с параметром, например `/?lang=ja`. Английская локаль грузится сразу, остальные подгружаются при переключении.

## Как добавить событие

1. В `js/data.js` добавь метаданные:

```js
{ id: "my-event", date: "2026-11-12", cat: "news", major: true,
  yt: "VIDEO_ID",                     // превью с YouTube (необязательно)
  img: "assets/events/my-event.jpg",  // своя картинка (необязательно)
  poster: "212 GB",                   // крупная цифра вместо картинки (необязательно)
  source: "https://…" }
```

2. В каждый файл `js/locales/*.js` в раздел `events` добавь `"my-event": ["Заголовок", "Текст"]`. Если дата неточная («2023–2025»), положи подпись в раздел `dates`.

`date` может быть `"YYYY-MM-DD"`, `"YYYY-MM"` или `"YYYY"`: формат даты на карточке подстроится сам под язык.

## Картинки к событиям

У трейлеров превью подтягиваются с YouTube автоматически. Для остальных положи файл в `assets/events/` и пропиши `img` в `data.js`. Если картинка не загрузилась, карточка просто покажет постер или текст.

## Перед публикацией

В `index.html` замени `SITE_URL` в `og:image` и `twitter:image` на реальный домен (например, `https://long-road-vi.vercel.app`), иначе X и Threads не покажут картинку в превью.
