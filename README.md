# Долгая дорога: хроника ожидания GTA VI

Неофициальный фанатский рекап тринадцати лет ожидания GTA VI (2013–2026): таймлайн событий в виде карточек и таймер до релиза 19 ноября 2026.

## Запуск

Сборка не нужна, это статический сайт:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Структура

- `index.html`: разметка (hero с таймером, бегущая строка, цифры, таймлайн, финал с кнопками «Поделиться»)
- `css/style.css`: стили и дизайн-токены (палитра в `:root`)
- `css/fonts.css`, `fonts/`: шрифт Onest (OFL), подключён локально
- `js/i18n.js`: тексты интерфейса на русском и английском
- `js/events.js`: **все события таймлайна** (RU + EN), категории и подзаголовки годов
- `js/main.js`: рендер, переключатель языка, фильтры, таймер, анимации
- `assets/hero.webp`: картинка для первого экрана (необязательно; без неё будет градиент)
- `og.png`: превью для X / Threads (1200×630)

## Язык

Язык выбирается так: `?lang=en` / `?lang=ru` в адресе → сохранённый выбор → язык браузера. Для постов на английском давай ссылку с `?lang=en`.

## Перед публикацией

В `index.html` замени `SITE_URL` в `og:image` и `twitter:image` на реальный домен (например, `https://long-road-vi.vercel.app`), иначе X и Threads не покажут картинку в превью.

## Как добавить событие

Добавить объект в `window.EVENTS` в `js/events.js`:

```js
{
  sort: "2026-10-01",                                  // ISO-дата для сортировки
  cat: "ads",                                          // ключ из CATEGORIES
  major: true,                                         // крупная карточка (необязательно)
  draft: true,                                         // пометка «Черновик» (необязательно)
  source: "https://…",                                 // ссылка на источник (необязательно)
  date:  { ru: "1 октября 2026", en: "October 1, 2026" },
  title: { ru: "Заголовок", en: "Title" },
  text:  { ru: "Описание", en: "Description" }
}
```

Таймер считает до полуночи 19.11.2026 по локальному времени зрителя (`RELEASE` в `js/main.js`).
